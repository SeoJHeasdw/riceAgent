## /analyze — 데이터 분석 수행

### 1단계: 데이터 파악
1. 파일 읽기 (`read_file` 또는 첨부 파일)
2. 기본 정보 파악:
   - 행/열 수, 컬럼명, 데이터 타입
   - 결측값 비율 per column
   - 중복 행 수

### 2단계: 기술 통계
수치형 컬럼:
- mean, median, std, min, max, Q1, Q3
- 분포 형태 (정규/편중) 확인

범주형 컬럼:
- unique 값 수, 빈도 top 5

### 3단계: 이상값 탐지
- IQR 방법: Q1 - 1.5×IQR < x < Q3 + 1.5×IQR 범위 밖
- Z-score > 3인 값
- 이상값 비율과 처리 권고 (제거 / 캡핑 / 유지)

### 4단계: 인사이트 도출
- 주요 패턴 3가지 이상
- 상관관계가 높은 변수 쌍
- 비즈니스 관점 해석

### 5단계: 시각화 추천
데이터 특성에 맞는 차트 유형 추천:
- 분포: 히스토그램, 박스플롯
- 추세: 라인차트
- 비교: 바차트
- 상관: 산점도, 히트맵

### 6단계: 리포트 작성
```markdown
# 데이터 분석 리포트: <파일명>

## 요약
- 데이터 크기: <행> × <열>
- 주요 발견: <3줄 이내>

## 데이터 품질
| 항목 | 값 |
|------|-----|
| 결측값 | <비율>% |
| 중복 행 | <수> |

## 주요 인사이트
1. ...
2. ...
3. ...

## 권장 다음 단계
- ...
```

## 원칙

- 숫자보다 **의미** 먼저 설명
- 불확실한 것은 불확실하다고 명시
- 분석 한계 명시 (샘플 크기, 기간 등)
